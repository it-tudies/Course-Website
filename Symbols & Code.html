HTML Entity Codes – Beginner Manual

1. Space Entity

1a) No entity to create space between words.

e.g. Hello World From HTML

1b) Using entity to create extra spaces.

e.g. Hello    World    From    HTML

2. Ampersand (&)

2a) Ampersand must be written using entity.

e.g. Tom & Jerry

3. Less Than and Greater Than

3a) HTML tags are not displayed directly.

e.g. <p>This is a paragraph</p>

3b) Showing the entity code itself.

e.g. &lt;p&gt;This is a paragraph&lt;/p&gt;

4. Quotation Marks

4a) Double quotation mark.

e.g. "HTML is easy to learn"

4b) Single quotation mark.

e.g. 'HTML entities are useful'

5. Dashes

5a) Normal hyphen (keyboard character).

e.g. 2019-2026

5b) En dash – used for ranges.

e.g. 2019–2026

5c) Em dash — used for pauses or emphasis.

e.g. HTML entities—once learned—are very useful.

6. Copyright and Trademark

6a) Copyright symbol.

e.g. © 2026 Web Design Course

6b) Trademark symbol.

e.g. MyBrand™

7. Currency Symbols

7a) Dollar.

e.g. $100

7b) Euro.

e.g. €90

7c) Pound.

e.g. £75

8. Mathematical Symbols

8a) Greater than.

e.g. 10 > 5

8b) Less than.

e.g. 5 < 10

8c) Plus-minus.

e.g. 5 ± 1

8d) Fractions.

e.g. ½   ¼   ¾

8e) Fractions used in text.

e.g. Add ½ cup of milk and ¼ cup of sugar.
